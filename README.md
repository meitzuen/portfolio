# Jamie Mei's Professional Portfolio

A modern, responsive personal portfolio showcasing my experience as a Software Developer and SQA Engineer.

🔗 **Live Demo:** [Here's the page URL](https://meitzuen.github.io/portfolio/)

---

## 🚀 Overview

This project is a complete modernization of my personal landing page. It features a clean, professional aesthetic with a focus on typography, smooth interactions, and a responsive layout that works across all devices.

### Key Features

- **Modern UI/UX:** Built with a minimalist design, utilizing soft shadows and glassmorphism.
- **Bilingual Typography:**
  - **English:** Montserrat Alternates
  - **Chinese:** jf-openhuninn (粉圓體)
- **Responsive Design:** Mobile-first approach using CSS Flexbox and Grid.
- **Semantic HTML5:** Improved SEO and accessibility structure.
- **Interactive Elements:** Smooth scrolling and hover effects for better user engagement.

---

## 🛠️ Built With

- **Frontend:** HTML5, CSS3 (Vanilla CSS)
- **Icons:** FontAwesome
- **Fonts:** Google Fonts (Montserrat Alternates, Huninn)
